## Кратко о проекте

«Пепельный Легион: Душа Павшего» — 2D-экшн-платформер о призраке павшего злодея, который собирает души убитых врагов, поднимает легион и идёт мстить Герою.

В репозитории две версии:

| Версия | Папка | Технологии | Запуск |
| --- | --- | --- | --- |
| Браузерная | `src/`, корень | TypeScript + Vite + Canvas 2D | `npm run dev` |
| Десктопная | `desktop/` | Electron + TypeScript + Vite + Canvas 2D | `cd desktop && npm run dev` |

Основная разработка последнего времени шла в **десктопной** версии. Браузерная версия сохранена и продолжает работать отдельно.

### Игровой процесс

- ✅ Главный герой — призрак павшего злодея, вся графика векторная и анимированная.
- ✅ Боевая система: клинок, адский огонь, лечение, рывок с инерцией, двойной прыжок.

### Ключевые механики и контент

- ✅ **Меню героя** (`Tab` / `I`): портрет, характеристики, красная полоса HP, эктоплазма, инвентарь, состав легиона.
- ✅ **Красные капли жизни** в HUD, уменьшенный аккуратный размер.
- ✅ **Белый кролик**: не больше одного на локацию, с ним нельзя драться.
  - «Погладить» — расколдовывает путника, даёт до 500 душ.
  - «Съесть» — снимает половину HP, кричит «НЕ МАТЕРИСЬ!» и убегает.
- ✅ **Инкуб-демон**: если кролика съели, в комнате босса этой локации появляется огромный светловолосый инкуб с 2 фазами вместо сюжетного босса.
- ✅ **Скрытые проходы**: фальшивая стена с трещиной в каждой обычной комнате, за ней капсула с монетами или душами.
- ✅ **Оазисы**: мирная комната без врагов, с водой, пальмами, светлячками и хранителем; постепенно лечит HP и ману.
- ✅ **Странствующий торговец**: один на локацию, без бесплатного полного лечения; алтарь убран.
- ✅ **Обучающая комната**: 10 шагов, два трупа для `E`/`F`, чек-лист, кнопка пропуска (`S` или клик). Показывается один раз.
- ✅ **Белые призрачки после смерти**: маленькие полупрозрачные духи и в эффекте гибели, и на экране смерти.
- ✅ **Свои SVG-спрайты**: можно заменить процедурную графику файлами из `desktop/assets/custom/`; есть `manifest.json` для масштаба, сдвига, прозрачности и отражения. Если файла нет — работает fallback.

### Известные ограничения

- Приложение **не подписано Developer ID** и не нотаризовано. При первом запуске macOS может попросить подтверждение: правый клик по иконке → «Открыть».
- DMG не выложен в GitHub Releases, поэтому скачать готовую сборку из репозитория пока нельзя.
- Сборка только под macOS arm64. Windows и Linux цели прописаны в `package.json`, но не проверялись.
- Нет автотестов и CI: проверка пока ручная, через `tsc`, сборку и QA-скриншоты.
- Нет сохранения прогресса между забегами, кроме флага пройденного обучения в `localStorage`.
- Кастомные SVG-папки пустые: система готова, но своих спрайтов в репозитории пока нет.

## Как проверить проект

```sh
# Браузерная версия
npm install
npm run dev

# Десктопная версия
cd desktop
npm install
npm run dev

# Сборка десктопной версии
cd desktop
npm run build
npm run package   # .app
npm run dist      # .dmg
```

Проверка типов отдельно:

```sh
cd desktop
./node_modules/.bin/tsc --noEmit
```
