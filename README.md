# Пепельный Легион

Браузерная игра на TypeScript и Vite.

## Локальный запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

## Деплой на Vercel

Импортируйте GitHub-репозиторий в Vercel. Framework preset: **Vite**, команда сборки: `npm run build`, папка публикации: `dist`. Переменные окружения не требуются.
